# hl.dsp.cursor.move_to_corner()

> 将光标移动到屏幕指定角落。

- **所属:** `hl.dsp.cursor`
- **关联:** [[move]]

---

## 签名

```lua
hl.dsp.cursor.move_to_corner({ corner, window? })
```

## 参数

| 参数 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `corner` | int | 是 | 0=左上, 1=右上, 2=右下, 3=左下 |
| `window` | 窗口选择器 | 否 | 默认当前 |
