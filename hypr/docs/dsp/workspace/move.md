# hl.dsp.workspace.move()

> 将工作区移动到指定显示器。

- **所属:** `hl.dsp.workspace`
- **关联:** [[swap_monitors]]

---

## 签名

```lua
hl.dsp.workspace.move({ workspace?, monitor })
```

## 参数

| 参数 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `workspace` | 工作区选择器 | 否 | 默认当前工作区 |
| `monitor` | 显示器选择器 | 是 | 目标显示器 |
