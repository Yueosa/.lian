# hl.dsp.focus()

> 切换焦点。支持方向、工作区、显示器、上一个窗口等多种目标。

- **所属:** `hl.dsp`
- **关联:** [[window|dsp/window]], [[workspace|dsp/workspace]]

---

## 签名

```lua
hl.dsp.focus({ direction = "l" })
hl.dsp.focus({ workspace = i })
hl.dsp.focus({ monitor = m })
hl.dsp.focus({ last })
hl.dsp.focus({ urgent_or_last })
hl.dsp.focus({ window = w })
```
