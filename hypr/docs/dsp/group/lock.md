# hl.dsp.group.lock()

> 锁定编组，防止自动解散。

- **所属:** `hl.dsp.group`
- **关联:** [[lock_active]], [[toggle]]

---

## 签名

```lua
hl.dsp.group.lock({ action = "toggle", window? })
```

## 参数

| 参数 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `action` | string | 否 | `"toggle"` / `"enable"` / `"disable"` |
| `window` | 窗口选择器 | 否 | 默认当前 |
