# hl.dsp.window.signal()

> 发送 POSIX 信号给窗口进程。

- **所属:** `hl.dsp.window`
- **关联:** [[kill]]

---

## 签名

```lua
hl.dsp.window.signal({ signal, window? })
```

## 参数

| 参数 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `signal` | int/string | 是 | 信号编号（如 9=SIGKILL, 15=SIGTERM） |
| `window` | 窗口选择器 | 否 | 默认当前活跃窗口 |
