# hl.dsp.window.fullscreen()

> 全屏/最大化窗口。

- **所属:** `hl.dsp.window`
- **关联:** [[fullscreen_state]], [[float]]

---

## 签名

```lua
hl.dsp.window.fullscreen({ mode = "fullscreen", action = "toggle", window? })
```

## 参数

| 参数 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `mode` | string | 否 | `"maximized"` / `"fullscreen"`（默认） |
| `action` | string | 否 | `"toggle"`（默认）/ `"set"` / `"unset"` |
| `window` | 窗口选择器 | 否 | 默认当前活跃窗口 |
