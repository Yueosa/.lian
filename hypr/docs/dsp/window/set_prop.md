# hl.dsp.window.set_prop()

> 动态设置窗口属性。

- **所属:** `hl.dsp.window`

---

## 签名

```lua
hl.dsp.window.set_prop({ prop, value, window? })
```

## 参数

| 参数 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `prop` | string | 是 | 属性名（如 `"opacity"`, `"no_anim"`） |
| `value` | any | 是 | 属性值 |
| `window` | 窗口选择器 | 否 | 默认当前 |
