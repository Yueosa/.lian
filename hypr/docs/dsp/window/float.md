# hl.dsp.window.float()

> 切换窗口浮动/嵌入状态。

- **所属:** `hl.dsp.window`
- **关联:** [[fullscreen]], [[pseudo]]

---

## 签名

```lua
hl.dsp.window.float({ action = "toggle", window? })
```

## 参数

| 参数 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `action` | string | 否 | `"toggle"`（默认）/ `"enable"` / `"disable"` |
| `window` | 窗口选择器 | 否 | 默认当前活跃窗口 |
